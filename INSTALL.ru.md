# Установка NixOS на `leggrowm-mini`

Эта инструкция рассчитана на полную замену Windows на Lenovo IdeaPad 3
(81W4). После запуска разметки будут удалены **все** данные с внутреннего
NVMe-диска: Windows, раздел Recovery и всё содержимое диска `C:`.

Не выполняйте команды, помеченные как уничтожающие данные, пока не сделаете
резервную копию и не убедитесь, что выбран именно внутренний NVMe.

## Что потребуется

- ноутбук, подключённый к питанию;
- стабильный Wi-Fi;
- USB-накопитель не менее 8 ГБ для установочного образа;
- **второй** USB-накопитель для этого репозитория и резервных копий;
- другой компьютер или телефон на случай, если потребуется посмотреть
  инструкцию.

## 1. Подготовка в Windows

1. Скопируйте все нужные документы, фотографии, ключи, пароли и файлы с
   ноутбука на внешний диск или в облако.
2. Убедитесь, что резервная копия действительно открывается с другого
   устройства.
3. Скопируйте конфигурацию на второй USB-накопитель. В PowerShell замените
   `E:` на букву этого накопителя:

   ```powershell
   Copy-Item -Recurse -Force C:\nix\Nixos-osnix E:\
   Get-ChildItem -Force E:\Nixos-osnix
   ```

   В выводе должны быть `flake.nix`, `disko.nix`, `.gitignore` и каталог
   `hosts`.
4. Скачайте с [официальной страницы NixOS](https://nixos.org/download/) образ
   **Graphical ISO, x86_64 Linux**. Графический образ проще для первого
   запуска, чем Minimal ISO.
5. По возможности сравните SHA-256 скачанного ISO с контрольной суммой на
   официальной странице:

   ```powershell
   Get-FileHash C:\путь\к\nixos.iso -Algorithm SHA256
   ```

6. Запишите ISO на первый USB-накопитель программой
   [balenaEtcher](https://etcher.balena.io/). Выберите ISO, выберите именно
   установочный USB и нажмите **Flash**. Все данные на этом USB будут удалены.
7. Безопасно извлеките оба USB-накопителя из Windows.

## 2. Загрузка установщика

1. Полностью выключите ноутбук.
2. Подключите установочный USB и USB с конфигурацией.
3. Включите ноутбук и сразу нажимайте `F12`, чтобы открыть меню загрузки.
   Если меню не появляется, используйте `F2` для BIOS или кнопку Novo
   (маленькая кнопка/отверстие на корпусе Lenovo).
4. В BIOS:
   - оставьте режим загрузки **UEFI**;
   - отключите **Secure Boot**;
   - не включайте Legacy/CSM-режим.
5. В меню загрузки выберите USB с NixOS, обязательно вариант UEFI.
6. В меню NixOS выберите графический установщик с настройками по умолчанию.

## 3. Подключение к сети и открытие терминала

1. В графическом сеансе установщика подключитесь к Wi-Fi через значок сети.
2. Откройте терминал сочетанием `Ctrl`+`Alt`+`T`.
3. Получите права администратора:

   ```sh
   sudo -i
   ```

4. Проверьте сеть:

   ```sh
   ping -c 3 cache.nixos.org
   ```

   Если команда не получает ответы, не продолжайте: подключитесь к Wi-Fi.
   Если Wi-Fi-адаптер не определяется, временно используйте USB-модем телефона
   или USB-Ethernet-адаптер.

## 4. Копирование конфигурации в память установщика

1. Найдите оба USB-накопителя:

   ```sh
   lsblk -o NAME,SIZE,MODEL,TRAN,FSTYPE,MOUNTPOINTS
   ```

   Внутренний диск должен быть примерно `477G`, моделью `SK hynix
   HFM512GDHTNI-87A0B`, и обычно называется `/dev/nvme0n1`.

   Не путайте его с USB: USB-накопители обычно называются `/dev/sda`,
   `/dev/sdb` и имеют меньший размер.

2. Файловый менеджер графического установщика обычно монтирует USB с
   конфигурацией автоматически. Найдите его путь:

   ```sh
   ls /run/media/nixos
   ```

   Если там виден каталог с меткой второго USB, посмотрите его содержимое:

   ```sh
   ls /run/media/nixos/<МЕТКА_ВТОРОГО_USB>
   ```

   Должен быть каталог `Nixos-osnix`.

   Если каталога в `/run/media/nixos` нет, смонтируйте USB вручную. В выводе
   `lsblk` найдите раздел второго USB (например, `/dev/sdb1`), но **не**
   внутренний `/dev/nvme0n1`, затем выполните:

   ```sh
   mkdir -p /mnt/config-usb
   mount /dev/sdb1 /mnt/config-usb
   ls /mnt/config-usb
   ```

   Далее используйте `/mnt/config-usb` вместо
   `/run/media/nixos/<МЕТКА_ВТОРОГО_USB>`.

3. Скопируйте конфигурацию во временный каталог. Замените путь после
   `/run/media/nixos/` на фактический путь вашего USB:

   ```sh
   cp -a /run/media/nixos/<МЕТКА_ВТОРОГО_USB>/Nixos-osnix /tmp/Nixos-osnix
   cd /tmp/Nixos-osnix
   ```

4. Убедитесь, что вы находитесь в правильном каталоге:

   ```sh
   ls -la
   ```

   Должны присутствовать `flake.nix`, `disko.nix` и `hosts/`.

5. Зафиксируйте версии зависимостей:

   ```sh
   nix --extra-experimental-features "nix-command flakes" flake lock
   ```

   Эта команда создаст `flake.lock`. Она не меняет диск ноутбука.

## 5. Проверка цели и удаление Windows

1. Откройте описание разметки:

   ```sh
   sed -n '1,120p' disko.nix
   ```

   В строке `device` должно быть `/dev/nvme0n1`. Если внутренний диск на
   самом деле имеет другое имя, **не запускайте разметку**: исправьте только
   это значение в `disko.nix`, затем снова проверьте файл.

2. Ещё раз сверяйте это с выводом:

   ```sh
   lsblk -o NAME,SIZE,MODEL,TYPE,MOUNTPOINTS
   ```

3. Только когда вы уверены, что `/dev/nvme0n1` — внутренний SK hynix
   примерно на 477 ГБ, выполните:

   ```sh
   nix --extra-experimental-features "nix-command flakes" run github:nix-community/disko/latest -- --mode disko ./disko.nix
   ```

   **Эта команда необратимо удаляет Windows и все данные с выбранного диска.**

4. После завершения проверьте результат:

   ```sh
   lsblk -f
   findmnt /mnt
   findmnt /mnt/boot
   ```

   Должны быть созданы:

   - EFI-раздел с меткой `boot`, смонтированный в `/mnt/boot`;
   - ext4-раздел с меткой `nixos`, смонтированный в `/mnt`.

## 6. Установка системы

1. Скопируйте подготовленную конфигурацию на установленный диск:

   ```sh
   mkdir -p /mnt/etc/nixos
   cp -a /tmp/Nixos-osnix/. /mnt/etc/nixos/
   cd /mnt/etc/nixos
   ```

2. Проверьте, что `flake.lock` тоже скопировался:

   ```sh
   ls -la flake.nix flake.lock disko.nix
   ```

3. Запустите установку:

   ```sh
   nixos-install --flake .#leggrowm-mini
   ```

   Загрузка и сборка могут занять длительное время. Не выключайте ноутбук и
   не закрывайте крышку.

4. После успешного завершения задайте пароль обычному пользователю:

   ```sh
   nixos-enter --root /mnt
   passwd leggrowm
   exit
   ```

   Используйте длинный уникальный пароль и сохраните его в менеджере паролей.
   Этот пароль нужен для входа и для `sudo`.

5. Перезагрузите компьютер:

   ```sh
   sync
   reboot
   ```

6. Когда экран погаснет или появится запрос, извлеките установочный USB.
   Второй USB с конфигурацией тоже можно извлечь.

## 7. Первый вход

1. В меню загрузки выберите внутренний диск/NixOS, если это не произошло
   автоматически.
2. На экране входа введите:

   - имя пользователя: `leggrowm`;
   - пароль, заданный на предыдущем шаге.

3. Если сеть не подключилась автоматически, откройте терминал (`Super` +
   `Enter`; `Super` — клавиша с логотипом Windows) и выполните:

   ```sh
   sudo nmtui
   ```

   Выберите **Activate a connection**, выберите Wi-Fi, введите пароль сети и
   выйдите из программы.

   Если графический сеанс ещё не позволяет открыть терминал, нажмите
   `Ctrl`+`Alt`+`F2`, войдите как `leggrowm`, выполните `sudo nmtui`, затем вернитесь
   в графический сеанс сочетанием `Ctrl`+`Alt`+`F1`.

4. Проверьте основные службы:

   ```sh
   systemctl status postgresql
   systemctl status avahi-daemon
   ```

   Для выхода из просмотра `systemctl` нажмите `q`.

   В исходной конфигурации SSH не запускается автоматически после загрузки.
   Когда он понадобится, запустите его вручную и проверьте состояние:

   ```sh
   sudo systemctl start sshd
   systemctl status sshd
   ```

## 8. Настройка Throne

1. Откройте меню приложений клавишей `Super` и найдите **Throne**.
2. Импортируйте свою подписку или профиль только через интерфейс Throne.
3. Не добавляйте URL подписки, ключи или экспортированный профиль в
   `/etc/nixos` и не коммитьте их в Git.
4. При необходимости сначала попробуйте режим **System Proxy** в Throne.
   TUN-режим требует дополнительных привилегий; не включайте его, пока
   System Proxy не будет проверен.

## 9. Как применять будущие изменения конфигурации

Конфигурация хранится в `/etc/nixos`. После изменения `.nix`-файлов:

```sh
cd /etc/nixos
sudo nixos-rebuild switch --flake .#leggrowm-mini
```

Если сборка завершилась ошибкой, текущая работающая система не будет заменена.
Для просмотра предыдущих поколений системы используйте меню GRUB при загрузке.

Не запускайте `nix flake update` без необходимости: оно обновляет зафиксированные
версии всех зависимостей.
